# 対応環境と機能一覧

Multi Column X は Windows・Linux・Android に対応しています。環境によって使える機能が異なるため、機能ごとの対応状況を一覧にまとめました。

- ○ … 利用できます
- × … 利用できません（未対応）
- － … その環境では必要ない、または別の手段で同等のことができます（備考を参照）
- △ … 一部条件付きで利用できます（備考を参照）

## インストールと更新

| 機能                         | Windows | Linux | Android | 備考                                                     |
| ---------------------------- | :-----: | :---: | :-----: | -------------------------------------------------------- |
| 配布形式                     |    ○    |   ○   |    ○    | Windows: `.exe` / Linux: AppImage・deb / Android: `.apk` |
| アプリ本体のアプリ内更新     |    ○    |   △   |    ○    | Linux は AppImage 版のみ。deb 版は手動で更新します       |
| 更新の自動チェック（起動時） |    ○    |   ○   |    ○    | 手動の「更新を確認」も全環境で使えます                   |

詳しくは [インストール](./install) と [アプリの更新](./update) を参照してください。

## 画面と操作

| 機能                         | Windows | Linux | Android | 備考                                                                                                                                         |
| ---------------------------- | :-----: | :---: | :-----: | -------------------------------------------------------------------------------------------------------------------------------------------- |
| ツールバー／タブバーでの操作 |    ○    |   ○   |    ○    | デスクトップは画面上部のツールバー、Android は画面下部のタブバーで操作します                                                                 |
| カラムの切り替え・移動       |    ○    |   ○   |    ○    | デスクトップはツールバーのカラム一覧、Android はタブで切り替えます                                                                           |
| スワイプでカラム切替         |   －    |  －   |    ○    | デスクトップは複数カラムを横に並べて表示するため不要です                                                                                     |
| キーボードショートカット     |    ○    |   ○   |   －    | 画面操作が中心の Android では不要です                                                                                                        |
| 複数カラムの同時表示         |    ○    |   ○   |    ○    | デスクトップは常に複数カラムを並べて表示します。Android は広い画面（横向き・タブレットなど）で設定により 2〜6 列表示できます（対応端末のみ） |
| カラムの並び替え             |    ○    |   ○   |    ○    | デスクトップはツールバー上のドラッグ、Android は「カラム配置」タブの ▲ / ▼ で並び替えます                                                    |
| ツールバーの折りたたみ／展開 |    ○    |   ○   |   －    | Android にはツールバーがありません（タブバーのメニューを開閉できます）                                                                       |
