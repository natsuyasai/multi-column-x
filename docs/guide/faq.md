# よくある質問・困ったとき

## TweetDeck の代わりに使えますか？

はい。Multi Column X は TweetDeck（現 X Pro）のように複数アカウント・複数カラムを横並びで表示するための **TweetDeck 代替アプリ** です。ホーム・通知・検索・リストなどをカラムとして並べ、自動更新や NG ワードもカラムごとに設定できます。ただし TweetDeck / X Pro とは別のアプリのため、画面や機能が完全に同じではありません。詳しくは [はじめに](./) を参照してください。

## カラムが真っ白になる／表示が乱れる

アプリ設定（`Ctrl+,`）→「一般」→「WebView」の **「全 WebView を再生成」** を押すと、全カラムが順番に作り直されます（設定は維持されます）。詳しくは [アプリ全体設定](./settings#アプリ全体設定) を参照してください。個別のカラムであれば、カラムヘッダーの **⟳（ページを再読み込み）** も試せます。

## ログインが切れた（Cookie が無効になった）

アカウント管理（`Ctrl+Shift+A`）で該当アカウントの **「再認証」** を押してログインし直します。詳しくは [アカウントを追加する](./accounts) を参照してください。

## インストール時に警告が表示される

Multi Column X は OS のコード署名を行っていないため、警告が表示されることがあります。Windows の SmartScreen では「詳細情報」→「実行」で続行できます。詳しくは [インストール](./install) を参照してください。

## 自動更新されない・更新が止まる

スクロール操作中は自動更新がスキップされます。また、カラムごとに自動更新の有効／無効や間隔を設定できます。詳しくは [カラムを使う](./columns#自動更新) と [カラム個別設定](./columns#カラム個別設定) を参照してください。

## ツールバーの「API」ボタンが表示されない

アプリ設定「一般」の「API残量モニター」が無効になっている可能性があります。詳しくは [初回起動と画面構成](./screen) を参照してください。

## Linux で動画が再生されない

AppImage 版は H.264 の動画デコーダを同梱していません。アプリ設定（`Ctrl+,`）→「一般」→「動画再生（Linux）」の **「H.264 を有効化」** を押すと、必要なデコーダを取得できます（反映には再起動が必要です）。deb 版や、デコーダを自分で導入する場合は、お使いのディストリビューションの GStreamer プラグイン（`gstreamer1.0-plugins-bad` と `gstreamer1.0-libav` など）を導入してください。詳しくは [設定](./settings) を参照してください。

## Linux で AppImage が起動しない

AppImage に実行権限が付いているか確認してください（`chmod +x MultiColumnX_*.AppImage`）。インストールスクリプトを使うと、実行権限の付与とアプリケーションメニューへの登録をまとめて行えます。詳しくは [インストール](./install#インストールスクリプトを使う-appimage-版) を参照してください。

## Linux の deb 版を新しいバージョンに更新したい

deb 版はアプリ内更新に対応していません。新しい `.deb` をダウンロードして上書きインストールしてください。詳しくは [アプリの更新](./update) を参照してください。

## 使いたい機能が自分の環境で使えるか知りたい

[対応環境と機能一覧](./environments) に、Windows・Linux・Android ごとの対応状況をまとめています。

## 設定の「拡張機能」タブが表示されない

拡張機能の管理は Windows 版のみの機能です。Linux 版や Android 版では表示されません。詳しくは [拡張機能](./settings#拡張機能-応用) を参照してください。

## 追加した拡張機能が動かない

一覧で拡張機能が「有効」になっているか、「見つかりません」と表示されていないかを確認してください。追加・有効化のあとは全カラムが自動で再読込されます。Chrome 固有の機能に依存する拡張機能は、一部の機能が動作しないことがあります。詳しくは [拡張機能](./settings#拡張機能-応用) を参照してください。

## 別の端末へ設定を引き継ぎたい

アプリ設定の「バックアップ」タブでバックアップファイルを書き出し、引き継ぎ先で復元します。ログイン情報は含まれないため、引き継ぎ先で先にアカウントを追加してください。詳しくは [バックアップと復元](./settings#バックアップと復元-応用) を参照してください。

## 新しいバージョンの通知をキャンセルしてしまった

アプリ設定（`Ctrl+,`）→「一般」→「アプリ情報」の **「更新を確認」** から、いつでも手動で確認できます。詳しくは [アプリの更新](./update) を参照してください。
