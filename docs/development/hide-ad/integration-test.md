# 広告非表示（「Ad from ○○」対応）手動テスト項目

## 前提
- 設定で「広告を非表示」が有効
- 実アカウントでログイン済みのホーム（おすすめ）カラム

## 項目
- [ ] おすすめタブを下へ 30 回以上スクロールしても「Ad from ○○」の広告が表示されない（通常ポストは表示される）
- [ ] 「広告を非表示」を無効にして再起動すると、「Ad from ○○」の広告が表示される（設定が効いている）
- [ ] 「Ad from ○○」を含む文面の通常ポスト（例: 本文に "Ad from" と書かれたポスト）が誤って消えない
- [ ] 外部リンクを含む通常ポスト（ニュース記事の引用等）が消えない
- [ ] 検索カラム・リストカラムでも広告が表示されない
- [ ] 全カラムで注入が動作している（NGワード・設定反映などが従来どおり効く）
- [ ] Android: ホームのおすすめで広告が表示されない（実機）
