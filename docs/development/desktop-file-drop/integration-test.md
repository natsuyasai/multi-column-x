# 手動テスト項目: デスクトップ版の画像ファイルドラッグ&ドロップ添付

対象: デスクトップ（Windows / macOS / Linux）。Android は対象外。

| #   | 手順                                                                                     | 期待結果                                                            |
| --- | ---------------------------------------------------------------------------------------- | ------------------------------------------------------------------- |
| 1   | コンポーズウィンドウを開き、エクスプローラ/Finder から画像ファイルを投稿欄へドロップする | 画像が添付プレビューとして表示される                                |
| 2   | 投稿カラム（インライン投稿フォーム）へ画像ファイルをドロップする                         | 画像が添付プレビューとして表示される                                |
| 3   | ポップアップ内の返信欄へ画像ファイルをドロップする                                       | 画像が添付プレビューとして表示される                                |
| 4   | 複数画像を同時にドロップする                                                             | 上限（4枚）まで添付される                                           |
| 5   | 画像以外（テキスト等）をドロップする                                                     | X 標準の挙動（添付されない/エラー表示）で、アプリがクラッシュしない |
| 6   | 従来のファイル選択ボタンでの添付                                                         | 従来どおり添付できる（回帰確認）                                    |
| 7   | カラム内でのタブ/リンクのドラッグ等、通常操作                                            | 影響がない                                                          |
