# 手動テスト項目: Android 複数カラム表示でタブ選択時に表示位置を動かさない

対象: Android タブレット（複数カラム表示が有効で 2 列以上同時に表示できる端末）。カラムは 4 つ以上登録（A, B, C, D）。

| #   | 手順                                                   | 期待結果                                                                         |
| --- | ------------------------------------------------------ | -------------------------------------------------------------------------------- |
| 1   | A, B 表示・A アクティブで、B のタブをタップ            | 画面上のカラム位置は変わらず、B が操作対象（ダブルタップ・戻る操作の対象）になる |
| 2   | A, B 表示・B アクティブで、A のタブをタップ            | カラム位置は変わらず、A が操作対象になる                                         |
| 3   | A, B 表示で、非表示の C のタブをタップ                 | C, D の表示へ遷移し、C が操作対象になる                                          |
| 4   | B, C 表示・B アクティブで次へスワイプ                  | 表示は B, C のまま、C が操作対象になる                                           |
| 5   | A, B 表示・B アクティブで次へスワイプ                  | B, C へ 1 カラム分ずれる                                                         |
| 6   | B, C 表示・B アクティブで前へスワイプ                  | A, B へ 1 カラム分ずれる                                                         |
| 7   | 表示中カラムのタブ選択を繰り返す                       | WebView のちらつき・再読み込み・白画面が起きない                                 |
| 8   | 表示中カラムを選択後、カラムを追加                     | 追加カラムが表示され、従来どおりアクティブ基準の位置になる                       |
| 9   | 表示中カラムを選択後、アプリをバックグラウンドから復帰 | クラッシュせず、アクティブカラムが復元される（窓位置はアクティブ基準でよい）     |
| 10  | 1 列表示（画面幅が狭い、または設定で無効）でタブ選択   | 従来どおり選択カラムが全幅で表示される                                           |
