# ブラウザ拡張機能 手動テスト項目

対象: Windows 版デスクトップの拡張機能の追加・管理（設計は `docs/development/browser-extensions-notes.md`）。
実施環境の前提: Windows 11 + WebView2 Runtime、Chrome インストール済み（拡張機能を 2 つ以上入れておく）、アカウント 2 つ以上、各アカウントにカラムがある状態。**特記が無い限り `npm run tauri:dev` または `tauri:build:debug` で確認する。**

「自動テスト済み」の観点（一覧・ボタン表示条件・エラー表示・reconcile 計画・パス検証など）は単体／結合テスト・Storybook・プロパティテストで担保済みのため、ここでは実機でしか確認できない項目のみ記載する。

## 実施メモ

- 自動検証済み（手動不要）: 一覧／追加／削除／有効無効の UI 状態とエラー表示、ポップアップ・オプションの表示条件、reconcile 計画（Add／Remove／SetEnabled／冪等性）、Chrome 検出（最新バージョン選択・多言語名・追加済み判定）、パス検証（`..` 等の拒否）、除外コピー（元フォルダ不変・再コピー抑止）、ACL 契約、全 builder へのフラグ付与の構造検査。
- 実機での未検証事項（`docs/development/browser-extensions-notes.md` の「既知の制約と未検証事項」）: 同一 ID の二重 Add、稼働中の拡張フォルダ削除、マップ済みネットワークドライブの扱い、`webview2.rs` の完了ハンドラ入れ子の実機動作。上記 No.1〜9 の実施時に併せて確認する。
